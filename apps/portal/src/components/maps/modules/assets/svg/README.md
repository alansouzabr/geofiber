# GeoFiber Maps - Biblioteca Oficial de Símbolos

Todos os SVGs seguem o padrão:

- SVG puro
- Fundo transparente
- Flat Design
- Sem gradientes
- Sem sombras
- Contorno preto (2px)
- Escala uniforme
- Anchor inferior central
- Compatível com Leaflet
- Compatível com React Leaflet
- Compatível com GIS
- Compatível com impressão
