# GeoFiber Maps - Design System

Objetivo

Biblioteca única de símbolos GIS para redes FTTH.

Todos os ícones devem seguir:

• SVG puro
• Fundo transparente
• Flat Design
• Sem gradientes
• Sem sombras
• Stroke preto 2px
• Poucos detalhes
• Alta legibilidade
• Escala uniforme
• Compatível com Leaflet
• Compatível com React Leaflet
• Compatível com QGIS
• Compatível com ArcGIS
